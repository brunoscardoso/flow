# Native Codex pilot brainstorm

Goal: exercise PlanFlow from a native Codex session and produce a reviewable draft PR.

Options considered: a business feature (no requirement supplied), a native installer rewrite (too broad), or a bounded CLI smoke fixture and truthful integration documentation (selected under the user's explicit scope).

The fixture should demonstrate the deterministic planning seam without a provider call, account changes, global installation or a shared knowledge store. Full app Autopilot parity is outside this pilot. No UI work is needed.
