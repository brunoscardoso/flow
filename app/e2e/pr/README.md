# Per-PR regression specs

Playwright specs generated by the QA heartbeat, one per merged PR that touches
the UI. Each `pr-<N>.spec.ts` exercises the feature that PR delivered and guards
against the specific bug/gap the heartbeat flagged.

- **Generated** by `flow/pr-verify-runbook.md` (the daemon writes the spec here).
- **Run in-session** via `npm run e2e` — the headless daemon does not run them.
- Naming: `pr-<number>.spec.ts` (e.g. `pr-70.spec.ts`).

These are ordinary specs — they use the same `../fixtures/electron` and
`../selectors` as the standing suite.
